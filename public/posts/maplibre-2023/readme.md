### MapLibre User Group Japanのはじまり

![img](https://memo.dayjournal.dev/images/try-105_03.png)  

2022年8月、[FOSS4G 2022 Firenze](https://2022.foss4g.org)で、これまでオンラインでのみつながりがあった[MapLibre](https://maplibre.org)のメンバーに直接会うことができました。この出会いは、私の中でMapLibreをより広く普及させたいという強い思いを生み出しました。

2022年12月、CoordinatorのOliverさんから「MapLibreのSWAGを送って良いかい？そしてMapLibre Ambassadorにならないか？」という提案を受けました。私は、個人としてではなく、MapLibreのユーザーグループを作りたいと返事をしました。

Oliverさんとやりとりする中で、[Kanahiro Iguchi](https://twitter.com/kanahiro_iguchi)を誘い、2人でコミュニティを立ち上げることにしました。そして2023年1月に[MapLibre User Group Japan](https://bit.ly/mug--jp)を作りました。このユーザーグループは、MapLibreの一部として、世界中に広がるコミュニティを目指しています。現在もMapLibre Ambassadorの役割は存在しません。

ユーザーグループの名称を、「MapLibre User Group 〇〇〇」としたのは、世界中のさまざまな国や地域で展開できるようにという願いが込められています。この取り組みにより、今では海外からユーザーグループ設立についての相談がくるようになりました。

<br>

### MapLibre User Group Japanとは

![img](https://memo.dayjournal.dev/images/try-105_01.png)  

MapLibre User Group Japan (MUG-JP)は、MapLibreプロダクトの開発者によるユーザーコミュニティです。ナレッジの共有やイベントの開催による普及活動を行なっています。MapLibreプロダクトを広めたい、そして技術的な交流の場を作りたいと思い活動しています！略して「MUG-JP(まぐじぇいぴー)」です！X(Twitter)のハッシュタグは「#mugjp」で発信お願いします！

<br>

### 運営メンバー

MUG-JPは、Geospatial好きなメンバーでゆるくマイペースで運営しています！また、メンバーは[MapLibre Voting Member](https://github.com/maplibre/maplibre/blob/main/VOTING_MEMBERS.md)として本体の投票権も持っています。MapLibre Voting Memberには、AWS・Meta・Microsoft・Elastic・Lyft・Felt・MapTiler・Protomapsのメンバーなんかもいたりします。
